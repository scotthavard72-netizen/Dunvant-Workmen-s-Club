What appears on the public What's On page

Add and edit events here — changes appear on the public What's On page instantly, no deploy needed. There's no automatic link to Facebook (Facebook's API doesn't allow reading a page's events without a lengthy Meta review, and it can break without notice), so if you've already posted an event there, just copy the details across here too. The optional "Facebook link" field adds a "More on Facebook →" link to the event for anyone who wants the full post.
