Live view of submitted tickets — updates automatically as people submit

Each Microsoft Form writes its responses to an Excel sheet in OneDrive automatically. Embed that sheet below (Excel Online → File → Share → Embed) and this page shows the real, current tickets — no manual updating, no badge number to keep in sync by hand.

To make this live

  1. Build the two Microsoft Forms (public footer link, and Bar Staff → Submit a Ticket) if not already done.
  2. In each Form's Responses tab, choose "Open in Excel" — this creates a live-updating sheet in OneDrive.
  3. Open that sheet in Excel Online → File → Share → Embed, and copy the generated link.
  4. Replace the two placeholder src values above with those links.
