Posting updates

Use the Facebook app or facebook.com directly to post events, photos, and announcements — anything posted there will also be what members see if they follow the page from the website's Members section.

Keeping the site in sync

The website's "What's On" and Gallery sections are static — they don't pull from Facebook automatically. After posting a new event or photo there, come back here (or ask in the Claude conversation) to add it to the website too.

Page roles

Facebook lets you add other admins/editors to the page itself, separate from this Site Admin login — worth doing in Facebook's own Page Settings if more than one person needs posting access.
