Overall Changelog

The big picture — what's been built, in plain English

This is different from Site Changelog (the automatic one pulled from GitHub) — that one shows every individual save as a raw commit message. This one is a hand-written summary of the actual milestones, easier to skim if you want the story of how the site came together rather than a technical log. Add a new entry here whenever a significant chunk of work is finished.
Public Site
  • Homepage built: hero, hours & contact, events, function room booking, gallery, FAQ, map
  • Real details added: phone number, address, email, opening hours, founding year
  • Member vs non-member comparison, to encourage joining
  • Dark mode added across the whole site, remembers your choice
  • Colour theme locked to green, gold, and orange throughout
Staff Area & Roles
  • Personal logins for each person, replacing shared passwords
  • Five roles: Bar Staff, Keyholder, Management, Committee, Site Admin — each stacking sensibly (e.g. Management also sees Bar Staff and Keyholder)
  • Keyholder split into Closing and Opening, plus a troubleshooting section (Alarm Fault, Till Discrepancy, Out-of-Hours Contact)
  • Shift Cover Request: routine via Form, urgent via Teams
  • Staff FAQ/Handbook, New Starter Checklist, Finances & Accounts
Tickets & To-Do Tracking
  • Public "Report an Issue" link and a staff "Submit a Ticket" option
  • Tickets page (Site Admin) showing both, built around live Excel embeds
  • Site To-Do List — a running checklist of every placeholder still needing real content
Site Admin Tools
  • Full Admin Dashboard — every page on the site in one place
  • Manage Staff Logins — form-based editor, with a direct "Save to GitHub" option
  • Face ID / Touch ID lock for Manage Staff Logins on a phone, once added to the home screen
  • Google Analytics setup guide
  • Content Quick-Edit Cheat Sheet — where to make common changes
  • Site Changelog — automatic, pulled from GitHub's own commit history
