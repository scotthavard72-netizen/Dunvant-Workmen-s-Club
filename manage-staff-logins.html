GitHub Connection (optional, but saves the copy-paste step)

One shared token for the club, used by whoever needs to publish — Management and Site Admin. Get it at github.com → Settings → Developer settings → Personal access tokens → Generate new token, scoped to just this one repository with "Contents: Read and write" permission, and set an expiry (90 days is sensible) rather than "no expiration."

Since it's shared, anyone with it can publish as if they were anyone — the "by [Name]" credit in Site Changelog only works if people stay logged into their own Staff Area account while doing it. Keep the token itself private (a password manager, not a group chat), and if it's ever exposed or someone with access leaves, revoke and regenerate it — that's the one clean-up step that matters here.
