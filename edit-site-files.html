Where the site's files live and how to update them

This is an example reference page — swap the file tree below for a link to the club's actual GitHub repo once it's set up, and update the note with the real repo name.
# dunvant-wmc-site (example repo layout) 📁 club-website.html ← homepage 📁 staff-area.html ← password gate, all 3 roles 📁 staff-rota.html 📁 pending-bookings.html 📁 shift-cover-request.html 📁 shift-cover-requests-mgmt.html 📁 till-card-lookup.html 📁 closing-checklist.html 📁 whats-on-this-week.html 📁 membership-till-system.html 📁 robots.txt

1. Find the file

Every page is its own plain HTML file, named for what it shows — e.g. hours and events live in club-website.html.

2. Edit it

On GitHub, open the file and click the pencil icon to edit directly in the browser — no coding tools required for small text changes.

3. Commit the change

Save with a short description of what changed (e.g. "update opening hours"). GitHub Pages rebuilds automatically — live within a couple of minutes.

4. Bigger changes

For anything more involved — new sections, redesigns, new staff tools — come back to the Claude conversation this site was built in and ask for what's needed.
