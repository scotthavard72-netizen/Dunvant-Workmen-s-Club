Alarm Fault

Who to call and what to do if the alarm won't set or trips

This is an example page — replace the contact details with the club's real alarm company and callout number.
1

Stay calm, check the panel

Look at the alarm panel display for a zone number or fault code — this tells the engineer what's wrong and speeds things up.

2

If it won't set on close

Don't force it or leave the building unset. Try once more, then call the alarm company's fault line rather than guessing.

3

If it's gone off unexpectedly

Check nothing's actually wrong (break-in, fire) before assuming it's a fault. If all clear, silence and reset per the panel instructions, then still log it — repeated false alarms need investigating.

4

Log it

Let management know what happened, even if you sorted it yourself — patterns matter more than one-off faults.
